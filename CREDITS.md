# Design and media credits

## Design inspiration

The active Astro implementation is original HTML and CSS informed by two public academic websites:

- [Martin Saveski's personal website](https://github.com/msaveski/www_personal) inspired the compact photograph/name introduction and horizontal section navigation. Its author explicitly invites others to use the website as a template and asks for a link back.
- [Hoiyeong Jin's personal website](https://github.com/myyzzzoooo/myyzzzoooo.github.io) inspired the figure-left, metadata-right publication hierarchy with venue badges and compact resource buttons.

No Jekyll templates, third-party profile images, or publication assets from those repositories are bundled into this site.
